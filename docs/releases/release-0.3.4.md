# Release v0.3.4

## What's new
- **Find cover & details**: the old Find info sheet is redesigned. It now searches on its own as soon as it opens and preselects the best match, so most songs need no typing.
- **Simpler choices**: one match card with full-width **Use this match** and **Cover only** buttons, a **Not this one?** list of other matches, and a single **Search yourself** field that understands "artist - title".
- **Cover only**: take just the artwork and keep your own title and artist.
- **Now Playing shortcut**: songs without art show a "Find cover & details" button on the placeholder cover.
- **Better matching**: "Artist - Title" tags are split properly, duplicate channel names are dropped, matches by the right artist rank first, and a title-only retry runs when title + artist finds nothing.
- **Clearer empty results**: "No results" shows which searches ran and a spelling hint.
- **Layout fixes**: Download screen buttons are stacked full width, and the sheet no longer squishes with wide fonts or large font sizes.

## Updating
- **From v0.3.3, v0.3.2, v0.3.1, v0.2.0 or v0.1.0**: install over it as usual. Nothing is lost.
- **From v0.3.0**: v0.3.0 was signed with a development key, so Android won't update it. Uninstall it first, then install v0.3.4. Uninstalling deletes your playlists; your music files are not touched.
