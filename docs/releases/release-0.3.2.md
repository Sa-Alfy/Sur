# Release v0.3.2

## What's new
- **About screen**: tap the ⓘ icon on the Playlists screen to see the app version, developer (Shariar Ahamed, [@Sa-Alfy](https://github.com/Sa-Alfy)), privacy note, and links to the source code and the GPL-3.0 license.

## Updating
- **From v0.3.1, v0.2.0 or v0.1.0**: install over it as usual. Nothing is lost.
- **From v0.3.0**: v0.3.0 was signed with a development key, so Android won't update it. Uninstall it first, then install v0.3.2. Uninstalling deletes your playlists; your music files are not touched.
