# Phase 13B phone test

Device: Oppo A1k (Android 9)

Use a song that can be downloaded again after testing.

## Checklist

- [ ] Delete a song that is in no playlist.
- [ ] Delete a song that is in two playlists; confirm both playlist counts drop and neither playlist shows a ghost entry.
- [ ] Delete the currently playing song; confirm playback moves to the next song.
- [ ] Cancel at the confirmation dialog; confirm the song remains available.
- [ ] Deny the storage permission; confirm the song remains available and the failure message is shown.
- [ ] Confirm in the Files app that the deleted file is gone.
- [ ] Android 10 and 11+ system dialog: UNVERIFIED, needs an emulator.
