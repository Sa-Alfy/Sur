# Phase 11B-2 phone test checklist

Device: Oppo A1k

- ☐ Download a song: download a track in the Download tab, verify it plays and its title, artist, and cover art display correctly.
- ☐ Re-download the same song: download the same track again, verify it still plays, the cover still shows, and there is only one copy in Music/Sur.
- ☐ Cancel a download midway: start a download, cancel it from the notification or Download tab, verify no partial file appears in Music/Sur and the Download tab returns to idle.
- ☐ Download after a cancel: download a track again after cancelling one, verify the fresh download completes and plays.
- ☐ Regression, normal link: download a normal song link as before, verify it downloads, plays, and shows tags and cover as in 11B-1.
- ☐ Cover kept on re-download: after re-downloading a song that already had a cover, verify the cover is still shown and has not disappeared.
- ☐ No leftover after a failed download: if a download fails, verify no partial or broken file is left in Music/Sur.
