# Phase 11B-1 phone test checklist

Device: Oppo A1k

- ☐ Create playlist: create a new playlist from the Playlists tab, verify it appears in the list.
- ☐ Rename playlist: rename an existing playlist, verify the updated title is displayed.
- ☐ Delete playlist: delete a playlist via the menu, confirm dialog, verify it is removed.
- ☐ Remove song: remove a track from a playlist in Playlist Details, verify the track is gone.
- ☐ Reorder songs: drag a track up/down in a playlist, verify the new order persists across navigation.
- ☐ Add songs: select tracks in the Songs tab and add to an existing or new playlist, verify they appear.
- ☐ Export playlist: export an M3U playlist file to storage, verify export success notification.
- ☐ Download song: download a track in the Download tab, verify playback and that its cover art displays.
